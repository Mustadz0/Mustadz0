### ⚡ Philosophy

Every tool here started from a real complaint on Reddit:
- **stripe-qbo-converter** ← r/bookkeeping: "Stripe QBO export is broken"
- **contract-scanner** ← r/smallbusiness: "Can't afford a lawyer for every contract"
- **price-tracker** ← r/ecommerce: "Manual competitor price checks are killing me"

**My goal:** Build the tool once, MIT license, no paywalls. If it saves you an hour, it's worth it.
